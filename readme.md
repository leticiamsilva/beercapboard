## Hello!
Esse é um projeto de quadro de tampinha de cerveja (beercapboard). 
Onde é possível guardar informaçãoes sobre as cervejas que tomou e guardar suas tampinhas em um quadro.

É um projeto com arquitetura de duas camadas separadas (aplicação com front end desacoplado, independente. É um SPA).
SPA Angular + api rest em node. Com arquitetura Express MVC


### Passos para rodar o projeto

<br>1- Verificar se tem o node instalado; para o front a versão mínima é a 21.
  ``` node -v ```

<br>2- Pode importar a pasta raiz do back e do front no VS Code e preparar os ambientes pelos passos abaixo:
 <br>2.1.1 abra o terminal e va para a pasta backend
 <br>2.1.2 no terminal, execute:  ```npm install```
 <br>2.1.3 Após terminar, execute:  ``` npm start ```
 <br>2.1.4 Para saber se funcinou, acesse a url: http://localhost:3000/health
<br>
 <br>2.2.1 volte para a pasta raiz e entre na pasta frontend 
 <br>2.2.2 no terminal, execute:  ```npm install```
 <br>2.2.3 Após terminar, execute: ```npm start```
 <br>2.2.4 Para saber se funcionou, acesse a url: http://localhost:5173/
